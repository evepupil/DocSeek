## 里程碑进度

- M0：严格 TypeScript、版本化配置、项目发现、来源注册表和四个 CLI 命令已经实现。
- M1：标题感知分块、超长内容处理、真实本地 Embedding、SQLite、增删改更新已经通过测试和当前项目实测。
- M2：中文语义、专有词、路径筛选、简洁文本和 JSON 已通过测试；真实查询准确定位到外部文档与标签章节。
- M3：全量门禁、生产依赖审计和 npm 包清单均已通过；`docseek@0.1.0` 已发布到 npm，发布提交为 `cfcfe1c`，标签为 `v0.1.0`。
- M4：混合排序、绝对分数、无答案判断、诊断和 24 条真实评测已经通过，实现提交为 `3c6b9bf`。
- M5：紧凑树、单分支压缩、高分优先和默认不限最终条数已完成；实现提交为 `82d1d4a`，InferForge 外部索引已保留。
- M6：全局 Agent 规则自动注入、手工修复入口和索引防污染已完成；实现提交为 `a64ed1f`，随 `docseek@0.2.0` 发布。
- M7：已完成 Transformers.js、直接 ONNX Runtime、FastEmbed 和 llama.cpp 首轮对比；当前生产候选采用 Transformers.js 底层模型接口、跨文件长度分桶、头尾 token 保留和 288 token 上限。冻结 InferForge 语料四次完整建库为 113.3 至 186.4 秒，中位数 144.1 秒，质量与 512 token 对照持平；性能稳定性、写库分段计时和跨平台验证继续进行。
