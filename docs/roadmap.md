# DocSeek Roadmap

项目目标：交付一个本地、极简、可发布到 npm 的语义文档定位 CLI，并为多来源、标签和跨项目检索保留稳定扩展边界。

| 里程碑                     | 目标                                                     | 状态   | 依赖 | 模块文档                                                                   | 退出标准                                                               |
| -------------------------- | -------------------------------------------------------- | ------ | ---- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| <a id="m0-工程基础"></a>M0 | 建立严格 TypeScript 工程、配置、项目发现和版本化数据边界 | 已完成 | 无   | [项目与配置](模块设计/项目与配置.md)、[命令行接口](模块设计/命令行接口.md) | CLI 可构建；能发现项目、生成配置和维护忽略规则；相关单测通过           |
| <a id="m1-文档索引"></a>M1 | 完成标题感知分块、本地 Embedding、SQLite 存储和增量更新  | 已完成 | M0   | [文档索引](模块设计/文档索引.md)、[向量与存储](模块设计/向量与存储.md)     | `init` 与 `update` 可运行；新增、修改、删除行为有测试依据              |
| <a id="m2-混合检索"></a>M2 | 完成中文友好的向量与 FTS5 混合搜索及稳定定位输出         | 已完成 | M1   | [混合检索](模块设计/混合检索.md)、[命令行接口](模块设计/命令行接口.md)     | 中文语义、术语、路径筛选、JSON 和简洁输出通过测试与样例验证            |
| <a id="m3-发布质量"></a>M3 | 完成 npm 发布配置、说明文档和全量门禁                    | 已完成 | M2   | [命令行接口](模块设计/命令行接口.md)、[向量与存储](模块设计/向量与存储.md) | 格式化、类型检查、静态检查、测试、构建和 `npm pack` 全部通过并形成提交 |

## 里程碑进度

- M0：严格 TypeScript、版本化配置、项目发现、来源注册表和四个 CLI 命令已经实现。
- M1：标题感知分块、超长内容处理、真实本地 Embedding、SQLite、增删改更新已经通过测试和当前项目实测。
- M2：中文语义、专有词、路径筛选、简洁文本和 JSON 已通过测试；真实查询准确定位到外部文档与标签章节。
- M3：全量门禁、生产依赖审计和 npm 包清单均已通过，实现提交为 `115a2e8`。
