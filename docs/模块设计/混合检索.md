# 混合检索模块

- **模块定位**：融合语义和关键词候选，返回稳定、可解释的文档定位结果。
- **对应代码**：`src/search/`、`src/application/execute-search.ts`、`src/application/search-docs.ts`。
- **所属 M 里程碑**：[M2 混合检索](../roadmap.md#m2-混合检索)、[M4 检索质量](../roadmap.md#m4-检索质量)、[M7 向量化性能优化](../roadmap.md#m7-向量化性能优化)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-06。

## 职责与边界

- 生成查询向量和 FTS5 查询词项。
- 区分发散候选词与完整问句，保留 CLI 参数边界。
- 获取向量与关键词候选。
- 计算词项覆盖、语义强度和加权排名融合，生成最终顺序和绝对检索分数。
- 过滤低可信候选，允许返回少于请求数量的结果。
- 应用路径、集合、来源和标签筛选。
- 返回定位结构，不读取或总结命中文档全文。

## 结构与数据流

```text
SearchRequest
  -> 候选词边界 -> 查询模式
  -> 查询 Embedding -> 向量候选
  -> 中英文词项     -> FTS5 候选
  -> 项目内候选词证据
  -> 查询词实际覆盖 + 语义距离
  -> 加权排名融合 + 可信度过滤
  -> SearchResult[]
```

公开 CLI 当前传递查询、候选词边界、数量和路径。集合、来源、标签已经存在于内部请求结构，等待后续命令开放。

## 关键决策

- 向量与 FTS 分别取足量候选，再进行融合。
- 默认路线权重为向量 0.45、关键词 0.55，RRF 常数为 8，让前列与后排拉开差距。
- 最终分数由排名融合 0.60、词项覆盖 0.20、语义强度 0.20 组成，不依赖本轮最高结果。
- 单字、常见问句词和过短词项不进入查询侧 FTS，减少偶然命中。
- 完整问句继续使用统一最低可信度；两路都位于前列时允许较低门槛。
- 候选词模式只在项目能识别足够候选词时放宽：单术语需要一条词面证据，多词包至少需要两条。
- 放宽范围限制在向量前三和关键词前三；语义距离只增加一个现有校准区间，防止候选池整体泄漏。
- 标题在 BM25 中权重更高。
- 中文使用分词、双字组合和短词组共同召回。
- 最终并列时按来源、文档位置、行号和片段标识稳定排序。
- 分数范围为 0 至 1，表示可跨查询比较的检索强度，不表示概率。

## 当前实现

M2 已实现中英文和代码标识符词项、中文分词与双字组合、向量精确检索、FTS5 BM25 和基础加权排名融合。路径、集合、来源和标签筛选在存储查询中生效。

M4 已完成以下调整：

- 查询侧过滤单个汉字、常见中英文问句词和过短词项。
- 关键词与向量排名分别占 0.55 和 0.45，纯关键词精确命中可以进入最终前列。
- 使用索引阶段已经保存的词项计算实际覆盖，避免搜索时再次解析每个候选。
- 将排名融合、词项覆盖和语义距离组合为绝对检索分数。
- 普通结果和强双路结果使用分级可信门槛，允许明确无答案时返回空。
- 每条结果继续使用路径和行号打破并列，保证顺序稳定。

原先被挤出前五的 README 精确词项现已排第一；明显无关的查询返回空。真实评测的正向前五命中率、精确术语第一名命中率、无答案识别率和稳定性均为 100%。

M7 的发散词优化继续沿用同一搜索入口：

- CLI 把每个候选词边界传到应用层，短术语与 2 至 5 个候选词进入候选词模式；含明显问句结构的输入仍走严格模式。
- 项目内词汇证据先约束是否允许放宽，避免任何短词包都无条件拿到向量结果。
- RRF 常数从 60 降到 8，排名融合占比从 0.35 提到 0.60，词面覆盖占比从 0.50 降到 0.20。
- `--explain` 会显示查询模式及 `signal`、`dual-route`、`term-vector`、`term-keyword` 四种放行原因。

冻结 InferForge 索引的 90 条发散词实测中，Recall@5 从 0.267 提升到 0.356，第一名命中从 0.111 提升到 0.133，意图覆盖从 0.600 提升到 0.767。向量前五与关键词前五的同库并集共有 36 条命中，融合保留 32 条，保留率为 0.889。

## 验证方式

- 中文同义表达由向量路召回。
- 项目术语和代码标识符由 FTS 路召回。
- 同时命中两路的结果获得更高排名。
- 纯关键词精确命中可以超过弱语义候选。
- 明确无答案的问题返回空结果，弱结果不会显示成 `1.00`。
- 完整问句和候选词两类无答案用例共同约束放宽边界。
- 路径筛选不会返回范围外结果。
- 相同输入重复搜索顺序一致。
- 空索引和无结果查询正常返回。
