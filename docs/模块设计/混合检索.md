# 混合检索模块

- **模块定位**：融合语义和关键词候选，返回稳定、可解释的文档定位结果。
- **对应代码**：`src/search/`、`src/application/search-docs.ts`。
- **所属 M 里程碑**：[M2 混合检索](../roadmap.md#m2-混合检索)、[M4 检索质量](../roadmap.md#m4-检索质量)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-03。

## 职责与边界

- 生成查询向量和 FTS5 查询词项。
- 获取向量与关键词候选。
- 计算词项覆盖、语义强度和加权排名融合，生成最终顺序和绝对检索分数。
- 过滤低可信候选，允许返回少于请求数量的结果。
- 应用路径、集合、来源和标签筛选。
- 返回定位结构，不读取或总结命中文档全文。

## 结构与数据流

```text
SearchRequest
  -> 查询 Embedding -> 向量候选
  -> 中英文词项     -> FTS5 候选
  -> 查询词实际覆盖 + 语义距离
  -> 加权排名融合 + 可信度过滤
  -> SearchResult[]
```

公开 CLI 当前只传查询、数量和路径。集合、来源、标签已经存在于内部请求结构，等待后续命令开放。

## 关键决策

- 向量与 FTS 分别取足量候选，再进行融合。
- 默认权重为向量 0.45、关键词 0.55，RRF 常数为 60。
- 排序综合排名融合、词项实际覆盖和语义强度；最终分数不依赖本轮最高结果。
- 单字、常见问句词和过短词项不进入查询侧 FTS，减少偶然命中。
- 普通候选使用统一最低可信度；两路都位于前列时允许较低门槛。
- 标题在 BM25 中权重更高。
- 中文使用分词、双字组合和短词组共同召回。
- 最终并列时按来源、文档位置、行号和片段标识稳定排序。
- 分数范围为 0 至 1，表示可跨查询比较的检索强度，不表示概率。

## 当前实现

M2 已实现中英文和代码标识符词项、中文分词与双字组合、向量精确检索、FTS5 BM25 和基础加权排名融合。路径、集合、来源和标签筛选在存储查询中生效。

M4 已完成以下调整：

- 查询侧过滤单个汉字、常见中英文问句词和过短词项。
- 关键词与向量排名分别占 0.55 和 0.45，纯关键词精确命中可以进入最终前列。
- 使用索引阶段已经保存的词项计算实际覆盖，避免搜索时再次解析每个候选。
- 将排名融合、词项覆盖和语义距离组合为绝对检索分数。
- 普通结果和强双路结果使用分级可信门槛，允许明确无答案时返回空。
- 每条结果继续使用路径和行号打破并列，保证顺序稳定。

原先被挤出前五的 README 精确词项现已排第一；明显无关的查询返回空。真实评测的正向前五命中率、精确术语第一名命中率、无答案识别率和稳定性均为 100%。

## 验证方式

- 中文同义表达由向量路召回。
- 项目术语和代码标识符由 FTS 路召回。
- 同时命中两路的结果获得更高排名。
- 纯关键词精确命中可以超过弱语义候选。
- 明确无答案的问题返回空结果，弱结果不会显示成 `1.00`。
- 路径筛选不会返回范围外结果。
- 相同输入重复搜索顺序一致。
- 空索引和无结果查询正常返回。
