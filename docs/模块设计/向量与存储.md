# 向量与存储模块

- **模块定位**：提供本地 Embedding、版本化 SQLite 存储和一致性事务。
- **对应代码**：`src/embedding/`、`src/storage/`。
- **所属 M 里程碑**：[M1 文档索引](../roadmap.md#m1-文档索引)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-03。

## 职责与边界

- 按批次生成文档和查询向量。
- 保存集合、来源、文档、片段、标签、向量和 FTS 数据。
- 管理数据库迁移、模型指纹和向量维度。
- 为索引替换和单文件更新提供事务。
- 不决定标题分块规则，也不格式化 CLI 输出。

## 结构与数据流

```text
IndexableChunk
  -> EmbeddingProvider
  -> Float32 向量
  -> IndexStore 事务
  -> documents / chunks / embeddings / FTS / tags
```

搜索时，存储层分别返回带稳定标识的向量候选和 FTS 候选。

## 关键决策

- 默认使用本地 multilingual-e5-small q8。
- 文档输入增加 `passage: `，查询输入增加 `query: `。
- sqlite-vec 负责余弦距离计算。
- 向量保存在普通表中，先使用精确扫描以支持任意组合筛选。
- 数据增长后可以把实现替换为 vec0，应用层接口不变。
- 标签使用关联表，标签变化不触发向量重建。
- 模型配置指纹不一致时拒绝增量混用。

## 当前实现

当前已经实现本地 Transformers.js Embedding、sqlite-vec 余弦距离、FTS5、版本化迁移和完整关系表。初始化在临时数据库完成后替换正式索引；单文档写入使用事务；模型指纹和向量维度不匹配时拒绝混用。

默认模型已通过真实网络、代理、缓存和推理验证，中文查询生成 384 维有限数值向量。当前项目最新索引包含 12 份文档和 110 个片段。生产依赖审计为 0 个已知漏洞。公开 npm 包完成 Windows 全局安装后，使用同一索引执行真实模型搜索成功。

## 验证方式

- 使用固定向量提供者验证写入和搜索，不下载真实模型。
- 验证外键级联、事务回滚和数据库迁移。
- 验证模型指纹、维度和配置不一致错误。
- 使用 sqlite-vec 对已知向量执行余弦距离查询。
- 初始化失败时旧数据库仍可用。
