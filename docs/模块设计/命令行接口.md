# 命令行接口模块

- **模块定位**：提供 Agent 可以稳定调用的命令、退出码和输出协议。
- **对应代码**：`src/cli/`、`src/index.ts`。
- **所属 M 里程碑**：[M0 工程基础](../roadmap.md#m0-工程基础)、[M2 混合检索](../roadmap.md#m2-混合检索)、[M3 发布质量](../roadmap.md#m3-发布质量)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-01。

## 职责与边界

- 解析 `init`、`update`、`status` 和 `search`。
- 校验参数并调用应用用例。
- 输出简洁文本或稳定 JSON。
- 统一错误、退出码和版本信息。
- 不直接访问 SQLite、解析 Markdown 或加载模型。

## 结构与数据流

```text
argv
  -> Commander 命令
  -> 应用用例
  -> 业务结果
  -> 文本或 JSON 格式化
  -> stdout / stderr / exit code
```

## 关键决策

- 默认搜索输出只有定位信息。
- `--snippet` 是显式调试选项。
- `--json` 输出中不混入进度或诊断文本。
- 多个查询参数按空格合并，方便 Agent 传入多个短语。
- MVP 不注册 `add`、`tag` 或全局搜索占位命令。
- 每个命令单独放置，未来新增命令不会扩大入口文件。

## 当前实现

当前已经实现 `init`、`update`、`status` 和 `search`。无参数时显示帮助；所有失败返回非零退出码。搜索支持 `--top`、`--path`、`--json` 和 `--snippet`，默认文本保持定位信息简洁。编译入口保留 shebang，npm 包通过 `bin` 暴露 `docseek`。

编译后的 CLI 已完成真实初始化、文本搜索、JSON 搜索、状态和无变化更新验证。npm dry-run 包含命令入口、运行代码、类型声明、README 和许可证。

## 验证方式

- 四个命令的成功与失败退出码。
- 默认文本输出和 JSON 快照。
- `--top` 边界、`--path`、`--snippet` 和多个查询参数。
- stdout 与 stderr 分离。
- 编译产物保留可执行 shebang。
- `npm pack` 中包含命令入口。
