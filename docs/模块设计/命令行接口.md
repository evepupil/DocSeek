# 命令行接口模块

- **模块定位**：提供 Agent 可以稳定调用的命令、退出码和输出协议。
- **对应代码**：`src/cli/`、`src/index.ts`。
- **所属 M 里程碑**：[M0 工程基础](../roadmap.md#m0-工程基础)、[M2 混合检索](../roadmap.md#m2-混合检索)、[M3 发布质量](../roadmap.md#m3-发布质量)、[M4 检索质量](../roadmap.md#m4-检索质量)、[M5 紧凑导航输出](../roadmap.md#m5-紧凑导航输出)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-03。

## 职责与边界

- 解析 `init`、`update`、`status` 和 `search`。
- 校验参数并调用应用用例。
- 输出简洁文本或稳定 JSON。
- 统一错误、退出码和版本信息。
- 不直接访问 SQLite、解析 Markdown 或加载模型。

## 结构与数据流

```text
argv
  -> Commander 命令
  -> 应用用例
  -> 业务结果
  -> 文本或 JSON 格式化
  -> stdout / stderr / exit code
```

## 关键决策

- 默认搜索输出只有定位信息。
- 默认定位信息按共同目录、文件、章节和行区间聚合，避免重复路径和标题。
- `--top` 是可选的最终条数限制，不传时输出召回池内全部可信结果。
- `--snippet` 是显式调试选项。
- `--explain` 是显式诊断选项，显示检索信号与阶段耗时。
- `--json` 输出中不混入进度或诊断文本。
- 多个查询参数按空格合并，方便 Agent 传入多个短语。
- MVP 不注册 `add`、`tag` 或全局搜索占位命令。
- 每个命令单独放置，未来新增命令不会扩大入口文件。

## 当前实现

当前已经实现 `init`、`update`、`status` 和 `search`。无参数时显示帮助；所有失败返回非零退出码。搜索支持 `--top`、`--path`、`--json`、`--snippet` 和 `--explain`，默认文本使用可折叠单分支的定位树。编译入口保留 shebang，npm 包通过 `bin` 暴露 `docseek`。

`--explain` 在文本或 JSON 中增加查询词、候选数量、语义强度、词项覆盖、两路名次、向量距离和各阶段耗时。未启用时，原有文本和 JSON 结构保持不变。

编译后的 CLI 已完成真实初始化、文本搜索、JSON 搜索、状态和无变化更新验证。npm dry-run 包含命令入口、运行代码、类型声明、README 和许可证。发布元数据提供公开仓库、项目主页、问题反馈地址和公开访问级别。

项目 README 已覆盖源码安装、首次建库、概念短语查询、紧凑树读法、增量更新时机、Agent 规则接入、当前边界和后续扩展方向；所有展示命令均与当前 CLI 参数一致。

## 验证方式

- 四个命令的成功与失败退出码。
- 默认文本输出和 JSON 快照。
- `--top` 边界、`--path`、`--snippet` 和多个查询参数。
- `--explain` 的文本和 JSON 诊断结构；未启用时保持原输出结构。
- stdout 与 stderr 分离。
- 编译产物保留可执行 shebang。
- `npm pack` 中包含命令入口。
