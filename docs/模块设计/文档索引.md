# 文档索引模块

- **模块定位**：把 Markdown 文档转换为带标题层级和准确行号的检索片段。
- **对应代码**：`src/markdown/`、`src/application/index-documents.ts`。
- **所属 M 里程碑**：[M1 文档索引](../roadmap.md#m1-文档索引)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-01。

## 职责与边界

- 解析 Markdown 标题与块级结构。
- 维护标题父子层级。
- 优先按章节切分，超长章节按块或行继续切分。
- 为每个片段保留原文、标题路径、起止行和内容哈希。
- 比较文件哈希并编排新增、修改和删除。
- 不负责模型推理细节和最终排名。

## 结构与数据流

```text
DiscoveredDocument
  -> Markdown AST
  -> 标题栈与章节
  -> 长章节拆分
  -> IndexableChunk
  -> Embedding 与存储
```

片段向量输入会附加标题路径，定位行号始终指向原始 Markdown。

## 关键决策

- 使用语法树源码位置，避免正则解析 Markdown 标题。
- 标题边界优先于字符上限。
- 单个超长块按行拆分，防止模型输入超限。
- 文件内容哈希决定是否需要重新处理。
- 文档身份由来源标识和来源内相对位置组成。

## 当前实现

当前使用 Markdown 语法树的位置数据建立标题栈和章节。普通章节保持完整，超长章节按块级节点拆分，单个超长行继续按字符窗口拆分且不丢失内容。每个片段保存标题路径、原文行号、正文和 SHA-256。

增量流程按“来源标识 + 来源内位置”对比文档 SHA-256。新增和修改文件重新生成该文件片段，删除文件级联清理。未变化文件不调用文档向量生成。

## 验证方式

- 多级标题、跳级标题和无标题文档。
- 中文标题、代码块、列表和长段落。
- 每个片段的起止行能对应回原文。
- 未变化文件跳过；修改文件替换；删除文件清理。
- 同一内容重复运行产生稳定片段。
