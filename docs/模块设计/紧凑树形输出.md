# 紧凑树形输出模块

- **模块定位**：把多个定位结果压缩为共同路径、文件、章节和行区间组成的稳定树，减少 Agent 上下文占用。
- **对应代码**：`src/cli/search-tree.ts`、`src/cli/output.ts`、`src/cli/create-cli.ts`。
- **所属 M 里程碑**：[M5 紧凑导航输出](../roadmap.md#m5-紧凑导航输出)。
- **当前状态**：已完成。
- **最近更新时间**：2026-09-03。

## 职责与边界

- 合并所有结果的共同目录和重复路径。
- 在文件节点下复用 Markdown 标题层级。
- 从行区间叶子向上计算命中数量和平均分。
- 生成稳定、紧凑、无需 JSON 解析的默认文本。
- 不改变召回、评分、可信度过滤和 JSON 协议。

## 结构与数据流

```text
已排序 SearchResult[]
  -> 共同目录
  -> 路径节点
  -> 去重后的标题节点
  -> 行区间叶子
  -> 向上汇总数量与平均分
  -> 稳定树形文本
```

## 关键决策

- 根节点只显示路径，不重复展示可以从子节点推出的统计。
- 有分叉或多个直属行区间的节点使用 `×数量 .平均分`，不打印字段名称。
- 只有一个子节点的连续目录、文件和章节使用 `/` 或 `›` 合并；最终只有一个行区间时直接放在同一行，省略重复的 `×1` 和平均分。
- 行区间使用 `L起-止 .分数`；单行省略重复终点。
- 文件名与文档第一层标题忽略标点后相同时，省略该标题。
- 不做列宽对齐，避免为视觉空格消耗上下文。
- 聚合不会合并不同文件，也不会把不连续行区间拼成一个范围。
- 分支按内部最高分优先排列，平均分、命中数和名称用于稳定处理同分结果。
- 未传 `--top` 时不截断最终可信结果；召回候选池仍有固定上限。
- 片段预览与检索诊断信息较多，显式启用时继续使用逐条详细输出。

## 当前实现

默认搜索已经使用紧凑树。构建过程先按路径、文件和标题建立树，再自底向上计算统计；渲染时折叠单分支链，保留所有可信行区间。JSON 协议和显式调试输出沿用逐条结果。

InferForge 实测查询 `SLA违约退款 SLA违约` 返回 99 个可信位置。紧凑树为 4,374 字符、125 行；同一结果的 JSON 为 21,582 字符、1,048 行。单分支折叠前的树为 6,778 字符、242 行。测试索引保留在 `.docseek/evaluations/inferforge/`。

完整门禁的格式、静态检查、严格类型、9 个测试文件共 29 项测试、构建和 npm 打包均已通过；24 条真实模型评测全部达标。实现提交为 `82d1d4a`。

## 验证方式

- 单文件多章节、多文件多目录和无共同目录。
- 文档标题与文件名重复时只显示一次。
- 每级命中数量、平均分和行区间分数正确。
- 输入顺序变化不改变树形输出。
- 平均分较低但包含更高分结果的分支排在前面。
- 未传 `--top` 时返回全部可信结果，显式 `--top` 仍能截断。
- JSON、片段和诊断输出保持兼容。
- 在 InferForge 126 份文档、1,598 个章节的外部索引上人工检查 token 压缩效果。

## 待扩展项

- 按文档角色控制树中优先级。
- 可选限制每个文件最多显示多少章节。
- 对连续或重叠行区间做安全合并。
- 为终端增加可选颜色，默认纯文本保持无颜色。
